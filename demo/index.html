快速上手

<script src="fanhua.iife.js"></script>
<script>
  Fanhua.init({
    size: [40, 110],   // 或单个数字，如 80
    position: 'page',  // 'screen' = 固定在屏幕上
    duration: 3000,    // 0 = 永驻
  })
</script>

插件会从自己所在的目录旁边找 img/flowers/。如果你的目录结构不一样，加一个 imgBase 指过去就行：

Fanhua.init({ imgBase: 'https://cdn.example.com/fanhua/flowers/' })

花是怎么来的

每一朵都是先用手绘插画的画风生成，再处理成透明底的方形贴图：抠掉白背景、按花朵本体裁切居中、缩到 256px 并压缩。每张都存了 WebP 与 PNG 两份，浏览器支持 WebP 就只下 WebP 那份——比 PNG 小三分之一，而且是无损的，花瓣边缘一个像素都没动。点击时从 100 张里随机抽一张贴上，所以同一页开出来的花几乎不会重样。

花型有 25 种——雏菊、玫瑰、郁金香、樱花、向日葵、莲花、菊花、三色堇、绣球、风铃草、芍药、牡丹、桔梗、鸢尾、百合、康乃馨、小苍兰、木槿、山茶、矢车菊、波斯菊、玉兰、大丽花、银莲花……每一种都配了 4 种颜色，加起来正好 100 张。

默认会在页面空闲时把 100 张图悄悄下下来，等你点击时就能立刻开花；不想让它占带宽的话，把 preload 关掉或者给个数字，就变成用到才加载。

滚到这里啦

如果你把定位方式切成 page，在这里点下的花会跟着页面一起滚动，像真的开在纸面上；如果切成 screen，花会钉在屏幕的那一点，页面怎么动它都不挪窝。试试就知道。

存活时间调成 0 的话，花会一直开着——开满一整页也是被允许的，"落花扫地"按钮随时可以帮你收拾。
